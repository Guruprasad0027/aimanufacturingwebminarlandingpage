# GREENCORE Premium AI for Manufacturing Experience

A competition-style responsive landing experience built with React, Vite, Three.js, GSAP ScrollTrigger, and Lenis.

## Install and run

```bash
npm install
npm run dev
```
Open the local address Vite prints (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Netlify deployment
1. Run `npm install` and `npm run build`.
2. In Netlify, create a new site and connect this repository, or upload the project folder through Netlify's deploy flow.
3. Build command: `npm run build`
4. Publish directory: `dist`

## Notes
- The registration form is a visual demo; it does not send or save personal information. Connect a secure backend/form service before collecting actual registrations.
- Webinar date, fee, speaker/event details are editable sample content; verify them before publishing.
- Images are hosted externally (Unsplash) and require an internet connection.
